## Em resumo
- Harness de agente: tutorial de 15 passos para construir um equivalente ao Claude Code. O autor afirma que o harness dele superou o Claude Code no Terminal-Bench usando Haiku.
- Brave Search API passa a aceitar pagamento de US$ 0,005 em USDC via x402. Carteira própria do agente pode substituir chave de API em alguns casos.
- Agentes de código longos exigem controles em código: avaliar e revisar cada experimento, limitar gastos, usar proxy para chaves e modelos, sobreviver a falhas e pausar para humano.

- Advisories CISA (libumqtt e OpenPLC) pedem checagem de versão e exposição de rede antes de patch.
- Afirmação de desempenho do harness no Terminal-Bench vem do próprio autor; não verificada.
- Pagamento por agente (x402) ainda exige decisão de quem controla a carteira e o limite de gasto.

## Termos desta edição
- **x402** — Protocolo que usa o código de status HTTP 402 para cobrar pagamento por requisição, sem conta ou chave de API tradicional.
- **Harness de agente** — Camada de código que roda o modelo, chama ferramentas, guarda estado e aplica limites ao redor do LLM.
- **Terminal-Bench** — Benchmark que avalia agentes de IA em tarefas executadas no terminal.
- **Loop transformer** — Arquitetura em que blocos do transformer são reaproveitados em ciclos, em vez de rodar uma única vez por passagem.
- **EDA** — Electronic Design Automation: softwares usados para projetar circuitos integrados e placas eletrônicas.
