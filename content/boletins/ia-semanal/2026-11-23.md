## 🔧 Novidades de agents
**Agent Harness: How I Built My Own Claude Code, Step by Step** — O que é um harness de agente e como construir um parecido com o Claude Code, em 15 passos, cada um com diagrama e prompt. Segundo o autor, o harness dele superou o Claude Code no Terminal-Bench usando Haiku. [1]
Por que importa: Serve de roteiro prático para quem quer entender ou montar a camada de orquestração de um agente antes de depender de ferramenta pronta. [1]

**Brave Search x402: Agent Wallet or API Key?** — A Brave Search API agora aceita pagamentos de US$ 0,005 em USDC via x402. O texto explica quando carteiras controladas pelo agente fazem mais sentido que acesso por chave de API. [2]
Por que importa: Para quem opera agentes, a escolha entre carteira do agente e chave de API muda o modelo de cobrança, controle de gasto e autorização. [2]

**Build Durable, Secure Long-Running Agents** — Como confiar em um agente de código durante a noite: avaliar e revisar cada experimento, limitar gastos no código, usar proxy para chaves e modelos, sobreviver a falhas e pausar para um humano. [3]
Por que importa: Quem roda agente sem supervisão precisa de limite de gasto no código, proxy de credenciais e checkpoint para retomar após falha. [3]

**Building PlanetScale with Insights Agent** — Três correções que o Insights Agent fez na API Rails da própria PlanetScale: uma checagem de feature flag reordenada, um índice que deixou uma query mais lenta e um índice que reduziu uma query de segundos para milissegundos. [4]
Por que importa: Mostra que agente pode propor índices e ajustes de query úteis em produção, mas cada mudança de índice precisa de medição antes de aplicar. [4]

**5 Best Claude.ai Skills for PowerPoint and Presentation Design in 2026** — Cinco skills do Claude.ai para PowerPoint em 2026: PPTX, Theme Factory, Brand Guidelines, Canvas Design e XLSX, conferidas contra os arquivos-fonte da Anthropic, com limites e prompts. [5]
Por que importa: Para quem monta skills de documentos, as skills de PPTX e XLSX dão referência de padrão e limites reais para reaproveitar. [5]

**datasette-charts 0.1a0** — Lançamento do datasette-charts 0.1a0. O protótipo foi feito com Claude Fable 5.2 e virou plugin completo, que funciona sobre qualquer tabela ou consulta SQL no Datasette e pode ser testado no Datasette Lite. [6]
Por que importa: Plugin de gráficos para Datasette funciona sobre qualquer tabela ou consulta SQL, útil para quem já usa Datasette em análise de dados. [6]

**GLM-5.4: Toward Generalized Coding with Our First Loop Transformer** — GLM-5.4, do laboratório chinês Z.ai, já está disponível. É o primeiro modelo com arquitetura de transformer em loop, em que cada camada pode rodar mais de uma vez por passagem, diferente do transformer padrão. [7]
Por que importa: Arquitetura de transformer em loop pode mudar custo e comportamento de inferência para código; vale testar antes de adotar. [7]

## 🔬 Papers e benchmarks de eficiência
**EDAGoat: An EDA-Aware Agent for Project-Level GPU Optimization** — A aceleração por GPU transformou a automação de projeto eletrônico (EDA), mas melhorar ferramentas já otimizadas por especialistas ainda exige muito trabalho manual. O artigo propõe agentes de código que rastreiem gargalos entre código do host e do device, preservando correção e qualidade do projeto. [14]
Por que importa: Indica que agentes de código para otimizar GPU começam a rastrear gargalos entre host e device, o que exige revisão de correção no resultado. [14]

**Double counting in LLM evidence fusion: exact posteriors separate rule compliance from posterior gain** — Modelos de linguagem combinam relatórios em recuperação, consenso multiagente e memória; tratar relatórios de uma fonte compartilhada como independentes conta a mesma evidência duas vezes. A instrução de contar cada fonte uma vez depende da linha de base de quem recebe, e precisar seu efeito exige uma referência exata. [15]
Por que importa: Se o agente recebe relatórios de fontes que compartilham origem, contar evidência duas vezes gera confiança falsa; a instrução de contar uma vez pode não bastar. [15]

## Termos desta edição
- **x402** — Protocolo que usa o código de status HTTP 402 para cobrar pagamento por requisição, sem conta ou chave de API tradicional.
- **Harness de agente** — Camada de código que roda o modelo, chama ferramentas, guarda estado e aplica limites ao redor do LLM.
- **Terminal-Bench** — Benchmark que avalia agentes de IA em tarefas executadas no terminal.
- **Loop transformer** — Arquitetura em que blocos do transformer são reaproveitados em ciclos, em vez de rodar uma única vez por passagem.
- **EDA** — Electronic Design Automation: softwares usados para projetar circuitos integrados e placas eletrônicas.
