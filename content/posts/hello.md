Thread é boa para um insight. Ruim para um argumento com premissa, contra-exemplo
e código. O formato força cortar exatamente a parte que dá o valor — o porquê da
decisão, o que quebrou antes, o que foi descartado.

Este blog é o destino desse excedente: artigos longos sobre sistemas de agentes,
LLMs e engenharia, escritos a partir de trabalho real.

```bash
hugo server -D
```
